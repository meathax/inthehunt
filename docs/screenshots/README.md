# README screenshots

Captured by the native In the Hunt executable during the 13 November 2026 release-candidate checks. Images were converted losslessly from BMP to PNG; no pixels were retouched, cropped or generated. The README scales them for display.

- undersea.png: stage-one gameplay, enhancements disabled.
- harbour.png: surface combat, enhancements disabled.
- ruins.png: stone boss scene, enhancements disabled.
- enhanced.png: the undersea scene with all optional effects enabled.
- options.png: the native video options menu.

provenance.json records each local source path, SHA-256 and dimensions. Source captures remain in the ignored build directory. These images document the port, not every mode or a new gameplay test. Original game imagery is copyright Irem; no ownership or standalone asset licence is asserted.
