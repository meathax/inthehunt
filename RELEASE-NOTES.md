# In the Hunt 0.9.0 Beta

Nearly feature-complete: all six stages, both endings and local two-player co-op, with optional visual enhancements and RecompLauncher support.

- Faster default rendering by skipping unused enhancement processing.
- Fixed Unicode installation paths and stuck input after controller disconnects.
- Preserved desktop fullscreen preferences and protected newer-format settings.

**Play:** extract **InTheHunt-Windows-x64.zip**, open **play.cmd** and select your own World `inthunt.zip` or `inthunt.7z`. Windows 10/11 x64 required; no game data included. Enhancements are off by default.

**Update:** back up `.local/world` and copy it into the new installation.

**Beta limits:** slowdown is approximate; live launcher, audio, GPU and physical-controller testing remains incomplete. Catalogue listing is pending.
